# SpaceTimeArc – CHNT 31 presentation

Talk "SpaceTimeArc: Systemarchitecture for networked spatio-temporal human-environment-interaction data management", CHNT 31, 11th November 2026, Vienna.

Source: `index.qmd` (Quarto, Reveal.js, 16:9). Layout: `custom.css` with Fira Sans from `fonts/` (SIL OFL). Figures: `figs/`; the figures from `01-…` to `13-…` come from [GeoScience-FAIRification-LOD](https://github.com/Research-Squirrel-Engineers/GeoScience-FAIRification-LOD) (CC BY 4.0, Florian Thiery). References: `references.bib`.

## Run it

Needs [Quarto](https://quarto.org) (rendered with 1.10.18). In this folder, Windows cmd:

    quarto render index.qmd && start index.html

Live preview while editing (re-renders on every save):

    quarto preview index.qmd

In the presentation: arrow keys or space to move, `S` speaker view, `F` full screen, `O` overview, `Esc` overview of all slides, Alt+click zooms into a figure.

## Export as PDF

Two ways, both give one page per slide (1280 x 720, 16:9).

**1. From the browser (always works).** Open `index.html?print-pdf` in Chrome, press Ctrl+P, destination "Save as PDF", margins "None", switch on "Background graphics", save.

**2. With the script `export_pdf.py`** (Python, uses the installed Chrome). Once: `pip install playwright`. Then, after rendering, in this folder:

    quarto render index.qmd && python export_pdf.py

This writes `SpaceTimeArc_CHNT31.pdf` (about 7 MB). A different name: `python export_pdf.py talk.pdf`. If Chrome is installed in an unusual place: `set CHROME_PATH=C:\path\to\chrome.exe` first.

The PDF is a build product; keep it out of the repository unless you want it there.
